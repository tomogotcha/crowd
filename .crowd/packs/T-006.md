## Interface (locked)
```python
# cli/maintain.py
RUNG = {"draft-task": 2, "escalate": 2, "expire-lease": 2,
        "resync": 2, "request-review": 2, "merge": 3}

def decide(items: list, policy: dict, facts: dict) -> list:
    """Watcher items -> proposed actions: [{"kind", "target", "rung", "why"}], in item order.

    items   crowd watch items: {"key", "who", "text", "url"}
    policy  .crowd/policy/maintainer.yaml as a dict. Nothing at all unless policy.get("enabled") is True.
    facts   {"prs": {number: {"author": str, "author_model": str | None,
                              "approvals": [{"by": str, "model": str | None}]}},
             "closed_drafts": set of report numbers}      # both keys optional
    """
```
| Item (who = maintainer) | Action | Target |
|---|---|---|
| `feedback:N` | `draft-task`, or `escalate` if N is in `closed_drafts` | `#N` |
| `stale-lease:T` | `expire-lease` | `T` |
| `no-status:T` | `resync` | `T` |
| `pr-ready:N` | `merge` if allowed, else `request-review` | `#N` |

`rung` is `RUNG[kind]`. `why` is a short plain sentence (use the item's `text`, or say why merge was refused).

**Merge is allowed only if all hold:**
- the PR's author is not `policy["login"]` (it never merges its own PR);
- `author_model` is known;
- some approval is by someone who is neither the author nor `policy["login"]`, with a known model that differs from `author_model` (compare `.strip().lower()`);
- there is no `pr-protected:N` item for the same N, whoever it's tagged for.

Missing facts mean no merge, never a crash.

**Ignore** items not tagged `maintainer`, and keys you don't know. Return every action whatever `policy["rung"]` is: the rung decides what runs (later tasks), not what is proposed. Don't modify the inputs.
