## Relevant code
`cli/crowd.py`, today:
```python
def detect_ram_gb():
    try:
        if platform.system() == "Darwin":
            return round(int(run(["sysctl", "-n", "hw.memsize"])) / 2**30)
        if Path("/proc/meminfo").exists():
            kb = int(re.search(r"MemTotal:\s+(\d+)", Path("/proc/meminfo").read_text()).group(1))
            return round(kb / 2**20)
    except Exception:
        pass
    return None
```
`GlobalMemoryStatusEx` fills a `MEMORYSTATUSEX` struct: `dwLength` (set it to the struct size first), `dwMemoryLoad`, then `ullTotalPhys` and six more 64-bit fields. Python 3.9 is the oldest supported version: no `match`, and write type hints as comments or with `Optional`.
