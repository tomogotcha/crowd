## Goal
`crowd survey` times a small standard compile and tags the machine card `fast_compile` when it's quick.

- One run = byte-compile every `.py` file in the stdlib `json` package, `REPEATS` (20) times, with `py_compile`, into a temporary directory.
- Take the median of `RUNS` (3) runs. Tag when the median is **strictly under** `THRESHOLD_S` (0.25 s).
- Store the median in `measured.compile_s_median`.
- A slower re-survey removes the tag. Nothing is written inside the repo.

## Serves
P8 (right work, right machine): build-heavy tasks can prefer quick machines, measured rather than declared.

## Where this sits
- Module: `cli` (see `.crowd/kb/modules/cli.md`). `cli/probes/` is planned there: one file per capability probe, each `probe() -> {tags, measured}`. This is the first one.
- Called by: `cmd_survey` in `cli/crowd.py`.
- Calls: stdlib only (`py_compile`, `json`, `statistics`, `tempfile`, `time`). No new dependencies.
